# Week 9 Tuesday: How the Web Works, HTML, and CSS

Each stage folder is a complete page you can open on its own. Stages build on each other, so compare a stage with the one before it to see exactly what changed.

| Folder | What it adds |
| --- | --- |
| `stage_1_html/` | Semantic HTML only: header, nav, main, sections, lists, image, table, aside, footer. No CSS. |
| `stage_2_css_basics/` | External stylesheet: selectors, cascade and specificity, units, color, the box model. |
| `stage_3_flexbox/` | Flexbox for the navigation bar and a row of cards. |
| `stage_4_responsive/` | Media queries so the layout adapts to phones and large screens. |
| `forms/` | `feedback_form.html`: form controls and what the submitted URL looks like. |
| `starter/` | Skeleton for the in-class activity: your personal page. |

## In-class activity: build your personal page

Use the `starter/` folder. Your page must have:

- [ ] A `header` with your name as the only `h1`
- [ ] A `nav` with at least three links that jump to sections of the page
- [ ] A `main` with at least two `section` elements, each with an `id` and an `h2`
- [ ] At least one list, one image with meaningful `alt` text, and either a table or a form
- [ ] A `footer` with a link to your GitHub profile
- [ ] An external stylesheet with a font stack, custom colors, padding, borders, and margins
- [ ] Flexbox used for the navigation or for a row of cards
- [ ] At least one media query
- [ ] Text and background colors with a contrast ratio of at least 4.5 to 1
- [ ] Passes the [W3C HTML validator](https://validator.w3.org/) with no errors

Push your work to a GitHub repository. On Thursday you will add JavaScript to this same page and publish it.
