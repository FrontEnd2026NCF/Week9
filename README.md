# CEN 3352 Week 9: HTML, CSS, and JavaScript

Front-End Development and Design, New College of Florida.

This week moves from Streamlit to writing web pages directly.

- `tuesday/` covers how the web works, HTML, and CSS (Oct 13).
- `thursday/` covers JavaScript, the DOM, events, and deploying with GitHub Pages (Oct 15).

All examples use the Case-Shiller home price index for Miami, Tampa, and the United States. The data is real: monthly values from January 1987 to June 2026, from the open dataset [datasets/house-prices-us](https://github.com/datasets/house-prices-us) (S&P CoreLogic Case-Shiller indices published through FRED, public domain license). The values are index levels, not dollar prices. A value of 100 is about the January 2000 price level.

## How to run any example

1. Open the folder in VS Code.
2. Install the **Live Server** extension if you have not already.
3. Right-click `index.html` and choose **Open with Live Server**.

Opening `index.html` by double-clicking also works for these examples.
